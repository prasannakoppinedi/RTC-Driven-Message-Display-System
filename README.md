RTC Driven Event Board – Message Display System
--------------------------------------------------------------------------------------------
📌 Project Overview
--------------------------------------------------------------------------------------------
The RTC Driven Event Board – Message Display System is an embedded systems project developed using the LPC2148 ARM7 microcontroller. It is designed to display important announcements, events, schedules, and real-time date and time information on a 16×2 LCD.

The system uses a Real-Time Clock (RTC) to maintain accurate time and date information. Users can manage and edit messages through a 4×4 matrix keypad using an admin interface with password authentication.

This project provides an efficient and user-friendly solution for displaying automated announcements in educational institutions, offices, and public places.

🎯 Objectives
--------------------------------------------------------------------------------------------
- Display real-time date, time, and day information.
- Display important announcements and event messages.
- Allow administrators to add, edit, and manage messages.
- Provide password-based access to the admin menu.
- Display temperature readings using the LM35 sensor.
- Indicate system status using LEDs.

🔑 Key Features
--------------------------------------------------------------------------------------------
- Real-Time Clock: Displays the current time, date, and day.
- Message Display: Displays predefined announcements and event notifications.
- Message Editing: Allows authorized users to edit messages through the keypad.
- Password Authentication: Protects administrative functions.
- Temperature Monitoring: Reads temperature data from the LM35 sensor using ADC.
- Status Indication: Uses LEDs to indicate different system conditions.
- LCD Scrolling: Displays longer messages using scrolling functionality.

🔌 System Working
--------------------------------------------------------------------------------------------
- The LPC2148 microcontroller initializes the LCD, RTC, keypad, ADC, and GPIO peripherals.
- The RTC provides real-time date and time information.
- The LCD displays the current time, date, and scheduled announcements.
- The user can access the admin menu using the keypad.
- Password authentication is performed before allowing message modifications.
- Authorized users can edit and update stored messages.
- The LM35 sensor provides temperature readings through the ADC interface.
- LEDs indicate the system status.
